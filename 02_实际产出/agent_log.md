## 执行链与角色分工

### Stage 1｜取数 Agent（脚本执行）
- 动作：并行抓取 7 个数据文件 → `原始数据/`
  - balance_600519.json（资产负债表 24 期）
  - income_600519.json（利润表 24 期）
  - cashflow_600519.json（现金流量表 24 期）
  - main_600519/000858/000568/600809.json（主要指标 ×4 家）
  - dividend_600519.json（分红台账）
- 质量控制：先探测字段名再写计算脚本，避免口径猜测；抓取失败自动重试补抓

### Stage 2｜勾稽 Agent（Python 确定性计算，scripts/compute_checks.py）
- 74 项机械勾稽：资产负债表 4 类恒等式 × 5 期、利润表 4 类 × 5 期、现金流量表 4 类 + 跨期衔接 × 4、跨表口径对比、指标回算 vs 披露值
- **结果：74 PASS / 0 FAIL / 5 NOTE（货币资金 vs 期末现金口径差）/ 5 INFO（净现比）/ 5 N/A（早期数据源未提供现金拆分字段）**
- 产出：`勾稽底稿.json`、`metrics.json`

### Stage 3｜质疑 Agent（红队，独立子 Agent 运行）
- 运行方式：独立 Agent，只读数据文件，输出独立报告
- 运行规模：约 158 分钟 / 23 次工具调用
- 产出：`Agent输出_质疑Agent.md`（6 项质疑，每项含证据→假设→核验方法→影响等级）
- 关键发现：合同负债 2026Q3 同比 -73.1%；净现比 0.72 主要是财务公司口径噪音（剔除金融项主业净现比 0.92）；回款票据化；销售/管理费用罕见背离

### Stage 4｜核查 Agent（终审核验，独立子 Agent 并行运行）
- 运行方式：与质疑 Agent 并行；**先独立复算、后比对结论**（防止被现成结论锚定）
- 运行规模：约 9 分钟 / 19 次工具调用
- 产出：`Agent输出_核查Agent.md`
- **结果：10/10 项独立复算与工作流结论一致，0 项不一致**；标注 3 处口径说明（EPS 加权平均股数、毛利率营业收入口径、营收倍数口径）
- 发布判断：可对外发布

### Stage 5｜终审整合（主 Agent）
- 对红队 4 项高/中级发现做关键数字抽查（合同负债 20.84 亿/-73.1%、应收票据及应收账款 52.35 亿、应收款项融资 44.57 亿、销售费用率 4.22%/+28.62%）——全部与原始数据一致
- 生成 `年报体检报告_贵州茅台2025.html`（自包含，内联 SVG）与 `勾稽底稿_贵州茅台2025.xlsx`
- 视觉自检：1200×900 浏览器渲染截图，检查首屏/红队区/同业表三处排版
- 一致性修正：同业表脚注 -54.5% → -54.6%（与表格四舍五入口径统一）
- **终审抓到真实错误并修复**：合同负债图表中 2026Q3 柱值最初误写为 2.1 亿（正确 20.8 亿，10 倍差错），被数字一致性自检脚本（HTML 标签 vs metrics/原始 JSON 比对）捕获后修复，并将该值改为从原始 JSON 现算以杜绝硬编码；收入柱标签同步改为单次舍入（1720→1721）

2. 五粮液 2025 年营收 -54.6% 一度被怀疑是数据错误，人工核查其 2024 年报与 2026 季报后确认数据自洽，属真实行业分化
3. 红队 Q2 的"剔除金融项净现比 0.92"为 Agent 分析结论，**待年报附注最终复核**，报告中已如实标注

## 复现方式

1. `bash scripts/fetch_data.sh`（或手动 curl）抓取原始数据
2. `python -I scripts/compute_checks.py` 生成勾稽底稿与指标
3. 按 `01_工作流蓝图/主指令_AutoClaw.md` 在 AutoClaw 中运行 Stage 3–4 的等价指令
4. `python -I scripts/build_report.py && python -I scripts/build_xlsx.py` 生成最终交付物
