## 这是什么

一套**上市公司年报体检工作流**：5 个 AI Agent 分工协作（取数 → 勾稽 → 质疑 → 核查 → 终审），
三道核验关（74 项勾稽、红队对抗、独立复算），把一份年报变成一页带证据链的体检报告。

已用贵州茅台 2025 年报实测：**勾稽 74/74 通过，独立复算 10/10 一致**，产出可直接截图的报告与底稿。
