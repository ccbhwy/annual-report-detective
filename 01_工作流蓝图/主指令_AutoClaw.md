# AutoClaw 主指令（可直接复制粘贴）

> 在 AutoClaw 桌面端新建对话，整段粘贴以下指令，把开头的证券代码换成你想体检的公司即可。
> 建议先看 `blueprint.md` 了解角色设计，跑完后按 `04_发布与核验/截图清单.md` 截图。

---

```text
你是「年报侦探」，请用多 Agent 工作流给一家 A 股上市公司做财报体检。
体检对象：贵州茅台（600519.SH）。全程分 5 个角色依次执行，每个角色完成后再进入下一个。

【角色1·取数Agent】
用命令行访问东方财富数据接口，抓取最近 5 个年报 + 最新季报的：
资产负债表、利润表、现金流量表（reportName 分别为 RPT_F10_FINANCE_GBALANCE / GINCOME / GCASHFLOW），
以及本公司和 3 家同业（五粮液000858.SZ、泸州老窖000568.SZ、山西汾酒600809.SH）的主要指标
（RPT_F10_FINANCE_MAINFINADATA），接口模板：
https://datacenter.eastmoney.com/securities/api/data/v1/get?reportName=<名称>&columns=ALL&filter=(SECUCODE%3D%22<代码>%22)&pageNumber=1&pageSize=24&sortTypes=-1&sortColumns=REPORT_DATE&source=HSF10&client=PC
所有原始 JSON 保存到「原始数据/」目录留档。抓取前先用 1 条请求探测字段名，确认字段存在再写解析代码。

【角色2·勾稽Agent】
写一个 Python 脚本（用 python -I 隔离模式跑），对最近 5 个年报逐期检查：
①资产=负债+所有者权益；②流动+非流动=资产总计；③归母权益+少数股东权益=权益合计；
④营业利润=营业总收入-营业总成本+其他收益+投资收益+公允价值变动+信用减值损失+资产处置收益；
⑤利润总额=营业利润+营业外收入-营业外支出；⑥净利润=利润总额-所得税；⑦归母净利+少数股东损益=净利润；
⑧经营+投资+筹资净现金流+汇率影响=现金净增加额；⑨期初现金+净增加额=期末现金；⑩本期期初现金=上期期末现金。
容差 1 元，输出 PASS/FAIL 明细（勾稽底稿.json）；同时回算 EPS、毛利率、资产负债率与披露值比对。
指标整理成 metrics.json（营收/归母净利及同比、毛利率、ROE、净现比、合同负债、存货）。

【角色3·质疑Agent】新开一个独立子任务，只许读数据不许改：
以红队姿态找 4–6 个值得人工复核的异常点（先行指标恶化、趋势背离、口径差异）。
每条必须含：证据（从 JSON 摘原始数字）、假设（明确区分"数据支持"和"待年报附注确认"）、核验方法、影响等级。
输出到「Agent输出_质疑Agent.md」。禁止为了戏剧性编造问题，报表干净就如实说干净。

【角色4·核查Agent】再开一个独立子任务，与角色3并行：
从「原始数据/」用 python -I 独立复算 10 个关键数字（不要先看角色2的结论，算完再比对），
输出比对表到「Agent输出_核查Agent.md」，并给出"能否对外发布"的判断。

【角色5·终审整合】
抽查角色3每个高/中级发现的关键数字是否与原始数据一致，抽查不过的发现直接删除；
然后把全部结果整合成一页 HTML 体检报告（自包含、内联 SVG 图表、不引外部JS）：
头部=体检结论三张卡（报表可信度/经营景气/股东回报），
正文=①勾稽结果统计 ②五年趋势图+指标表 ③红队发现卡片（每张附终审抽查结果）④同业对比表 ⑤核验与数据溯源，
页脚=生成时间+数据来源+免责声明。同时生成 Excel 勾稽底稿（勾稽明细/趋势/同业/红队四个 sheet）。

硬性要求：
- 所有金额保留原始精度，展示时标注单位（元/亿元）
- 报告中每个数字必须可溯源到「原始数据/」里的文件
- 发现口径差异（如货币资金 vs 现金流量表期末现金）时如实标注"需解释"，不许静默放行
- 最后输出一份运行日志（agent_log.md）：各角色做了什么、耗时、人工介入点
```

---

## 跑完之后

1. 打开生成的 `年报体检报告_*.html`，浏览器全屏截图（这是你社媒发布的主图）
2. 检查「原始数据/」「勾稽底稿.json」「Agent输出_*.md」是否齐全——缺任何一个都说明工作流没跑完整
3. 按 `04_发布与核验/截图清单.md` 补齐过程截图
4. 把你复核时发现的 AI 错误/口径问题写进发布文案的「使用经验」段——**这段最值钱**
