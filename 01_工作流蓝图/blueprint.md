# 「年报侦探」多 Agent 工作流蓝图 v1.0

> 一套可复用的上市公司财报体检工作流：5 个角色、6 个交付物、3 道核验关。
> 适用于 AutoClaw 桌面端（也适用于任何具备"运行代码 + 读文件 + 联网"能力的 Agent 产品）。

## 为什么设计成多 Agent？

单 Agent 一口气做完取数→分析→写报告，最大的问题不是慢，而是**没有人管它算得对不对**。本工作流把"算"和"验"拆开，用角色对抗制造核验压力：

| 角色 | 职责 | 关键约束 | 交付物 |
|---|---|---|---|
| ① 取数 Agent | 抓财报原始数据 | 原始文件必须留档（证据链） | 原始 JSON |
| ② 勾稽 Agent | 机械核验报表恒等式 | 只做确定性计算，不做判断 | 勾稽底稿 |
| ③ 质疑 Agent | 红队找异常 | 推测必须标注"待核验" | 质疑清单 |
| ④ 核查 Agent | 独立复算关键结论 | **先复算后看结论**，防锚定 | 比对表 |
| ⑤ 终审整合 | 出报告、抽查红队数字 | 每个对外数字可溯源 | 体检报告 |

## 三道核验关（这是工作流的灵魂）

1. **勾稽关**：资产=负债+权益、净利润=利润总额-所得税……恒等式不通过的直接 FAIL
2. **对抗关**：质疑 Agent 的目标是"找茬"，核查 Agent 的目标是"推翻同事"——两者都沉默才算过
3. **溯源关**：报告里每个数字要么来自原始 JSON，要么被终审抽查过；抽不过就下架

## 数据与工具清单

- 数据源：东方财富 F10（`datacenter.eastmoney.com/securities/api/data/v1/get`，reportName 三表 + MAINFINADATA）
- 计算环境：Python（标准库即可；Excel 用 openpyxl）
- 容差约定：勾稽差异 ≤ 1 元判 PASS（浮点+披露精度）

## 标准运行流程

```
Step1 取数      curl 三表+主要指标+分红 → 原始数据/*.json（留档）
Step2 勾稽      python compute_checks.py → 勾稽底稿.json / metrics.json
Step3 质疑      Agent 只读数据 → 6 项质疑清单（独立运行）
Step4 核查      Agent 独立复算 10 项 → 比对表（与 Step3 并行）
Step5 终审      抽查红队关键数字 → HTML 报告 + Excel 底稿
```

## 换一家公司怎么改？

1. 全局替换证券代码（如 `600519.SH` → `000858.SZ`）与公司名
2. 勾稽项无需改动（通用恒等式）；**注意**：金融类公司（银行/保险）三表结构不同，需另配勾稽模板
3. 同业对比数组换成同行业 3–4 家
4. 若某字段缺失（如早期年报无现金拆分），工作流会输出 N/A——如实标注，不要硬凑

## 已知边界（诚实声明）

- 勾稽全过 ≠ 财报无假（体外循环、关联交易藏表外）；它能证明的是"内部自洽+与披露值一致"
- 红队的口径分析（如财务公司业务影响净现比）需年报附注最终确认
- 东财接口字段偶有变动，取数前先探测字段名（本工作流已内置该步骤）
